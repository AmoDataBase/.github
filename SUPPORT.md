# Support

## Where to ask

| You need | Go to |
|---|---|
| Help with an API key, billing, a payment or an account | support@amodb.dev |
| A data correction (wrong title, rating, date) | support@amodb.dev with the endpoint, the id, the field and a source |
| API usage questions | [Docs](https://amodb.dev/docs) and [quick start](https://amodb.dev/quickstart) |
| What an error code means | [Errors](https://amodb.dev/errors) |
| HTTP 429 responses | [Rate limits](https://amodb.dev/rate-limits) |
| Is the API up | [Status](https://amodb.dev/status) |
| A bug in an SDK, the MCP server, the spec or an example | An issue in the matching repository |
| A feature request for an SDK | An issue in the matching repository |
| A security problem | security@amodb.dev, see [SECURITY.md](SECURITY.md) |

## Before you open an issue

1. Update to the latest release of the package.
2. Search the open and closed issues of the repository.
3. Collect the package version, the runtime version, the request path without your key, the UTC time and the HTTP status.

## What not to send

Never post an API key, a password or a payment detail in an issue, a pull request or an email. We never ask for them.
